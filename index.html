About

Selected work

AI assistant that searches public-sector documents

Led the project: design, build, launch

Two AI agents working together. A main agent talks to the user and decides whether a question needs a document search at all. A second agent does the searching with only the information it needs, checks whether what it found is enough to answer, and hands the result back through the main agent so the conversation stays complete. Packaged with Docker and running on the client's live and test servers.

  • LangGraph
  • ChromaDB
  • Docker
  • On-prem VM
